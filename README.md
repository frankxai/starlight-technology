# Starlight Technology

Buying intelligence and complete-system design for AI-native creators and small teams.

## Launch wedge

**AI Creator Studio** — evidence-led guidance for choosing local-AI computers, creator laptops, studio audio, music hardware, mobile capture, and complete systems by workload and budget.

- Public product: <https://starlight.technology>
- Authority bridge: <https://www.frankx.ai/stack>
- Open intelligence substrate: <https://starlightintelligence.org>

## Editorial promise

Every recommendation declares its evidence status, source dates, intended user, wrong-purchase conditions, complete-system cost, and lower/higher-budget alternatives. Research-only conclusions never imply hands-on testing.

## Technology workspace

- `/shop`: six source-backed decision records across compute, mobile, display, spatial and robotics; local TF-IDF vector search and category filtering.
- `/shop/studio`: deterministic workload brief, conservative hold conditions, browser-local save and JSON export/import.
- `/shop/estate`: local ledger for machines, phones, displays, headsets and research robots; portable JSON. No remote sync, credentials or control commands.
- `/api/technology/catalog`, `/api/technology/search`, `/api/technology/decision`: versioned read-only interfaces for future site, extension and MCP clients.

The [operating contract](docs/TECHNOLOGY_OPERATING_SYSTEM.md) defines media rights, claim/offer separation, neural-embedding upgrade gates, merchant adapters, R2, Railway and robot authority. Public routes make no live price or availability claim.
