# Editorial and Evidence Standard

Every decision page includes:

1. Intended user and objective.
2. Wrong-purchase conditions.
3. Decision-relevant specifications only.
4. Evidence status: owned-and-tested, hands-on, source-backed or inferred.
5. Source URLs and verification dates.
6. Complete-system cost boundary.
7. Alternatives.
8. Decisive conditional verdict.

## Forbidden

- Copied merchant descriptions presented as analysis.
- Fake first-person testing.
- Unverified live price or availability.
- “Best” without a named user and failure condition.
- Generated mass pages without a human decision model.
- Affiliate destination masking that violates programme rules.

## Lifecycle

Draft → source check → editorial check → compatibility check → publish → scheduled re-verification → correction/archive.
