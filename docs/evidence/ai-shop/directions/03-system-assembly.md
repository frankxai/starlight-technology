# Direction 03: System assembly

Alternative documented 7 October 2026. Not selected or implemented.

Grounding: existing original hardware category schematics, local-AI planning shortlist, complete-system builds and compatibility constraints.

Composition: an exploded system sheet leads with runtime, compute and recovery rows. A build selector drives the visible system; evidence and model licence records stay beside each layer. The free brief becomes the commissioning sheet behind the assembly.

Decision artifact: a complete local workflow with compute/memory, approved model/runtime and independent recovery path. No component is presented as independently benchmarked.

Benefit: coherent system procurement for machine-led campaigns and local-AI comparison traffic.

Tradeoff: it prioritizes hardware purchasing over the only immediately ready original AI product, the free planning kit. It risks duplicating the newly shipped hardware shop. Workshop brief was selected while existing hardware remains linked in place.

The existing schematics are category drawings, not device-accurate photography. Any future system campaign requires actual workload evidence and fresh visual review.
