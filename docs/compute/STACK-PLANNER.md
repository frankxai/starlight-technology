## Reading these numbers

- Unified-memory machines share one pool between the system and the model, so system and model memory add up.
- A memory class that fits only at the low estimate is a risk, not a plan.
- Langfuse's documented 16 GiB is the largest single line; running it on another small node or using a hosted option changes the result.
- GPU jobs are sized by VRAM only. A card that fits a job can still be slow.
- Estimates come from one profile of a laptop and must be replaced by the node's own measurements.
