### t02: Linux max GTT/GPU memory (~124GB)?

Status: verified.

AMD ROCm docs: GTT default is about 50% of RAM; recommended approach is a small BIOS VRAM reservation (e.g. 0.5GB) and raising the TTM/GTT limit (pages_limit, amd-ttm helper). The ~124GB figure is verified as a community configuration: kyuz0 guide sets amdgpu.gttsize=126976 (~124GB) and ttm.pages_limit=32505856. A llama.cpp issue (#14854) reports a 124GB GTT setup on Fedora 42. AMD docs give no officially guaranteed maximum number; 124GB is not an AMD-published cap.
